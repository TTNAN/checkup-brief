## 下一步（按优先级）

1. **更多医院报告版式**：美年、爱康、慈铭、瑞慈、公立医院等常见报告的排版差异（只用脱敏示例）。
2. **多页报告分科室**：按“生化 / 血常规 / 一般检查”分组展示。
3. **更多指标**：尿常规、肿瘤标志物、同型半胱氨酸、维生素 D 等的别名和参考范围。
4. **可选的大模型讲解**：OpenAI 兼容接口开关，只发已判好的异常指标，不发报告全文；默认关闭。
5. **PWA**：可安装到手机桌面，离线打开。

- 不做账号系统、不存用户真实报告、不做云端同步。
