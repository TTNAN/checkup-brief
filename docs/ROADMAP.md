# 路线图

> 只做健康科普，不做诊断，不能替代医生。

## 已完成（v0.1）

- [x] 一页纸人话简报：总分、红黄绿灯、逐项讲解、分享卡片
- [x] 中文体检解析器：30 个指标别名归一，报告单参考范围优先
- [x] 体检套餐选择器：加查 / 可选 / 可省
- [x] 挂号 + 问诊清单：科室、带什么、问什么
- [x] 30 天改善计划：吃 / 动 / 睡，每周主题，每日打卡
- [x] 静态演示页：双击打开，中 / EN 切换，离线可用
- [x] README 中英双语、MIT License、CI

## 下一步（按优先级）

1. **更多医院报告格式**：收集美年、爱康、慈铭、瑞慈、公立医院等常见报告的版式差异，补别名和解析规则（只用脱敏示例）。
2. **截图与演示**：给 README 补三张真实截图（简报、解析器、30 天计划），只用示例数据。
3. **解析准确率测试**：给 `src/parser.js` 补一组脱敏测试用例，覆盖别名、单位、血压、参考范围缺失等情况。
4. **可选的大模型讲解**：在本地模板讲解之外，提供一个可选的 OpenAI 兼容接口开关，只发已判好的异常指标，不发报告全文；默认关闭。
5. **打印友好的简报**：一页纸简报支持直接打印 / 导出 PDF，方便带去见医生。

## 明确不做

- **多年趋势热力图**：已和用户确认不做，不进入路线图。
- 不做诊断、不开药、不给剂量、不做在线问诊。
- 不做账号系统、不存用户真实报告、不做云端同步。
