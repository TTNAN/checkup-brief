# 隐私说明

> 只做健康科普，不做诊断，不能替代医生。

## 核心承诺

1. **默认本地处理**：解析、计分、推荐全部在你的浏览器或本地 Node 里完成，不上传到任何服务器。
2. **不收集数据**：演示页没有统计、没有埋点、没有第三方请求，不用外部字体、图片和 CDN。
3. **不存储报告**：关闭页面后，你粘贴的报告文字就消失了。30 天打卡目前只存在页面内存里，刷新即清空；如需持久化，请只存在你自己的浏览器本地存储里，不要同步到云端。
4. **示例数据已脱敏**：仓库里唯一的体检数据是 `examples/` 下的 32 岁男性示例，不含姓名、身份证号、电话、医院名称等任何真实个人信息。

## 请你也注意

- 不要把真实体检报告提交到本仓库的 Issue、PR、截图里。
- 不要把演示页的链接发给别人时附上你自己的真实报告截图。
- 如果你在公开场合分享简报，请先确认截图里没有姓名、医院、就诊号等信息。

## 如果未来接 AI 接口

如需把讲解交给大模型生成，必须做到：

- 只发送“已判好的异常指标 + 数值”，不发送报告全文；
- 默认不开启云端模型，开启前明确告诉用户数据会发到哪里；
- 提供纯本地模板讲解作为默认选项（即现在 `src/briefing.js` 的做法）。
